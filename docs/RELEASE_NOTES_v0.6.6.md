# PixelForge v0.6.6

- Open multiple projects in one session with independent image histories and settings. Image jobs return their results to the project that started them, even if you switch tabs.
- Organize thumbnails in named, collapsible groups. Select multiple thumbnails with Ctrl-click, drag thumbnails between groups, and drag groups to reorder them. Version names travel with their images.
- Open a thumbnail or an entire group as an independent, unsaved project. When opening a group, choose whether to keep the group in the new project.
- Edited versions join the source image's group. New imports and generations join the selected group. Existing project files remain supported.
- Batch export thumbnails and create valid JPEGs.
- Access Setup & Diagnostics, Dependencies, and Model Library from the Setup menu. PixelForge remembers the chosen model folder and suggests a default on a fresh installation.
- Find Pony Diffusion V6 XL and FLUX.1 options in Model Library, and continue supported interrupted downloads. SDXL inpainting preserves the original image outside the mask.
- Use Cut and Copy on selected prompt text from the right-click menu. Send an AI Assist suggestion straight to Initial Prompt while keeping the scratchpad available for further drafts.

The Windows release includes an installer, a portable ZIP, and SHA-256 checksums.
