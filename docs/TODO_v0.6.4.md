# Pixel Forge v0.6.4 to-do list

## Themes

User-requested scope, deferred from v0.6.3. Planning only; do not implement as part of v0.6.3.

- Offer Dark, Light, Windows, and Custom theme choices in Settings > Appearance.
- Preserve the current palette as the default Dark theme.
- Windows mode follows the Windows dark/light preference, including preference changes.
- Provide custom color controls for every colored application UI element so users can choose their own palette, including panels, headings, text, buttons, fields, borders, accents, selections, and interaction states.
- Allow up to five saved custom theme presets, with names, selection, editing, and replacement.
- Persist the chosen theme and all custom presets across restarts.
- Apply changes immediately and provide a way to return to a built-in theme.
- Check readability and consistent coverage across menus, dialogs, tabs, workspace controls, and disabled/hover/focus states.

## Remaining v0.6.3 work (separate scope)

- Remember the last monitor, windowed size and position, and fullscreen state across restarts.
- Require Alt+wheel over sliders to adjust values; Ctrl+Alt gives decimal precision and Shift+Alt steps by five. Wheel alone scrolls the panel. Direct numeric fields retain their existing wheel controls.
